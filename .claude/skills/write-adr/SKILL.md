# /write-adr

1. Read the diff / discussion and the ADR template at `docs/decisions/0001-template.md`.
2. Find the next number (`ls docs/decisions/`).
3. Draft one page: Context, Options considered (with pros/cons), Decision, Consequences (good + bad), Alternatives rejected and why.
4. Keep it honest: name what you don't know yet and what would change the decision.
5. Present the draft for approval, then save as `docs/decisions/NNNN-short-title.md`.

ADRs are interview gold. A stack of 5–10 good ADRs across BidHaus and your next project is worth more than 5 more features.
